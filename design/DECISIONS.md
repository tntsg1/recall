## 融合霓虹行者定案（grilling 5 轮，2026-10-27）
背景：用户嫌横版《霓虹行者》"没有手感、跳不高"，把它的玩法并进归弹；游戏改名《霓虹行者》，仍是俯视角。原霓虹行者项目冻结（GitHub tntsgdi/NEON-RAID 保留）。

**改名与世界观**
- 中文《霓虹行者》，英文 NEON RAID；标题画面子弹飞回拼出 NEON RAID，下写霓虹行者；窗口名 / exe 名 / 项目名一起改。仓库 tntsg1/recall 和网站 /recall/ 暂不动。
- 世界观换成霓虹行者：主角 R-0（700 年前旧文明原型机，能把意识射进机器），地下城第十三街。五章改成霓虹城市地点（暂定：地下调车场 / 镜面商场 / 吞噬工厂 / 节拍夜店 / 归零核心），Boss 机制不变，只改名字和外观设定。核心机制仍叫"回收"。
- 画风：全游戏换赛博朋克配色（青 = 你、红 = 敌人、品红点缀、深蓝紫地面网格、霓虹灯牌），仍是归弹的矢量几何画法与动画；被附身的敌人是霓虹行者的青色霓虹像素风。
- 配乐：保留归弹每章四轨自适应配乐；打击音换成霓虹行者的分层打击音。
- 开局加约 1 分钟教学关：射击 → 回收 → 标记 → 夺壳。

**夺壳**
- 触发：回收子弹贯穿过的敌人被标记几秒，按 E 意识射进最近的被标记敌人。
- 开局就有基础夺壳：附身 5 秒、冷却 8 秒。夺壳流派卡：1 级时长 +50% 标记更久；2 级连锁（壳结束时自动跳进附近标记敌人）；3 级能力强化一档 + 自爆范围翻倍。
- 附身时原身体消失、你就是那台敌人：WASD 移动、左键专属能力、Q 照样回收（子弹飞回壳上）、E 提前退出、不能开枪。
- 结束：负荷满壳自爆伤周围；壳被打爆也直接还原、不扣裂痕；还原后 1 秒无敌。
- Boss 本身不能夺，Boss 放出的小怪能夺，壳的能力能打 Boss。
- 七种壳：小怪平时弱，附身后伤害约 ×3，每种三段连招（第 3 段大招终结）+ 与回收的专属配合；终结慢镜 + 大字连击，不弹伤害数字：
  - 追击者：钻头冲刺 → 再冲 → 螺旋钻；冲刺时按 Q，回收弹沿冲刺轨迹追上去
  - 盾卫：盾推 → 横扫 → 盾冲把一串敌人顶到墙上；压在墙上时回收伤害 ×2；举盾正面无敌
  - 冲锋者：冲锋 → 撞墙反弹再冲 → 第 3 段撞墙引爆；冲过的路线留红线，沿线回收加伤
  - 棱镜：单道光束 → 分 3 道 → 棱镜爆 12 道；回收弹穿过你时每颗折射成 3 颗
  - 吸附者：按住聚怪 → 收缩挤压 → 引爆；聚怪时回收子弹一次穿过整团
  - 脉冲体：踩拍冲击环 → 连踩两拍变大 → 第 3 拍超大冲击；拍点上回收的子弹同时起飞 ×1.5
  - 回声：留分身 → 第 2 个 → 全部分身重走路线并爆炸；回收时每个分身也射出回收弹
- 也带霓虹行者的打击反馈：连击、终结慢镜、撞墙反弹、碎块、分层命中音。不带近战挥刀和横版跳跃。

**顺序**
1. 先做追击者 + 吸附者两种壳的完整版（标记、E、连招、回收配合、打击反馈、像素外观）给用户试手感
2. 用户点头后铺开到其余 5 种
3. 流派卡、Boss 战、机器人平衡
4. 改名 + 世界观 + 赛博朋克配色 + 教学关
每个里程碑提交并推送 tntsg1/recall；开发在 cshi_dev，测试全过再同步到 cshi。

## 配色回到黑白（2026-10-27）
赛博朋克多色（青/红/品红/蓝紫）两版用户都不满意："还不如黑白配色和主题色的"。定为：黑底白线 + 信号红只属于回收；青色只属于夺壳（被附身的壳、标记、地面像素感染）。灯牌保留但只用淡白色。
